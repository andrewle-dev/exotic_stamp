# Mobile App

Flutter app cho Metro Stamp mobile experience.

## Initial scope

- Auth
- Station list/detail
- QR scan
- Stamp book
- Rewards

## Key folders

- `lib/app/`: app shell, router, theme, bootstrap.
- `lib/core/`: network, storage, DI, shared services.
- `lib/features/`: feature modules (auth, scan, stamp_book, rewards, …).
- `lib/shared/`: DTO, models và reusable widgets.
